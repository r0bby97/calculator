# Calculator

A browser-based calculator created as part of
[The Odin Project Foundations course](https://www.theodinproject.com/lessons/foundations-calculator).

The project focuses on combining JavaScript fundamentals with DOM manipulation,
event handling, and a calculator-style user interface.

## Assignment

Build an on-screen calculator that can perform basic arithmetic operations.

The calculator will support:

- Addition
- Subtraction
- Multiplication
- Division
- Number input through on-screen buttons
- Displaying the current input and calculation results
- Clearing the current calculation
- Chaining multiple calculations together

## Current Features

- Calculator interface created with HTML
- Display area for calculator output
- Number buttons from `0` to `9`
- Decimal point button
- Addition, subtraction, multiplication, and division buttons
- Equals button
- Delete, clear, percentage, and positive/negative buttons
- Different button colors for numbers, operators, and special functions
- Basic calculator layout and styling with CSS
- Separate JavaScript functions for:
  - `add()`
  - `subtract()`
  - `multiply()`
  - `divide()`

## Planned Features

- Connect number buttons to the display
- Store the first and second operands
- Store the selected operator
- Create an `operate()` function
- Perform calculations when the equals button is pressed
- Update the display with calculation results
- Allow calculations to be chained together
- Implement clear and delete functionality
- Handle decimal input
- Prevent invalid operations such as division by zero
- Complete the remaining special-function buttons

## Built With

- HTML5
- CSS3
- JavaScript
- Flexbox
